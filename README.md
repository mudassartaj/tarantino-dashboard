# Tarantino Movies Dashboard

## 📖 Overview
Interactive dashboard analyzing profanity and deaths in Tarantino movies using Streamlit.

## 📂 Project Structure
- `data/` → Dataset (tarantino.csv)
- `notebooks/` → Jupyter/Colab analysis
- `app.py` → Main Streamlit dashboard
- `charts.py` → Chart functions
- `filters.py` → Sidebar filters
- `requirements.txt` → Libraries list
